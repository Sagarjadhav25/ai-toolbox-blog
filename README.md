# AI ToolBox

A fast, static technology publication focused on practical AI, coding, careers, productivity, and developer workflows.

## First article

- **10 AI Tools to Use in 2026**

## Stack

- Semantic HTML
- Modern CSS
- Vanilla JavaScript
- GitHub Pages
- GitHub Actions deployment

## Deployment

The workflow in `.github/workflows/deploy.yml` deploys the repository to GitHub Pages when `main` changes. In repository settings, Pages should use **GitHub Actions** as its source.

## Editorial note

AI product features and pricing change frequently. Product claims in the launch article were checked against official sources on September 3, 2026. Readers should confirm current plan details on linked official product pages before purchasing.
